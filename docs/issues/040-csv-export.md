## What to build

Let data leave the portal. Administrators reconcile against spreadsheets, and a
filtered list that cannot be exported forces manual retyping.

Export respects the active filters and sort and covers the **whole filtered result**, not
the visible page. It is generated by the mock from the same query the list used, so the
file and the screen can never disagree — which is why it is a query parameter on the
existing endpoints rather than a separate one.

Escaping is the part that only fails against real data: a venue containing a comma, a
quote or a newline must survive the round trip. Money exports as a decimal with its
currency in a separate column so a spreadsheet can sum it; dates in ISO-8601 for
unambiguous parsing; references by name.
